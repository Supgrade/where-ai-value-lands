# Contributors

Everyone who has had a contribution merged into this repository.

Author listed first. New entries appended at PR merge time, in chronological order of first merge.

## Roll

- Gabriele Dalla Costa — author and maintainer (2026–)

## Format

Each entry is a single line:

```
- <name or handle> — <one-line description of contribution kind> (<year of first merge>–)
```

Examples of valid one-line descriptions:

- `author and maintainer`
- `sources on European industrial AI adoption`
- `daily-thought contributor (operator perspective)`
- `concept extensions on agentic orchestration`

If a contributor wants to be listed by GitHub handle instead of name, that is fine — note it in the PR description.

## Why this file exists

The wiki's value is the coherence of one author's reading of the field. Every contributor who clears the merge bar is also helping carry that coherence — they earn a line here, and the paper's acknowledgements section credits substantive contributions separately. See [`CONTRIBUTING.md`](CONTRIBUTING.md) and the [contributor charter](wiki/01_paper-planning/08_contributor-charter.md).
